## ✨ Features

| Feature | Description |
|---|---|
| **🎨 Dark Glassmorphism** | Premium dark-first palette with frosted-glass cards and neon accents |
| **🌌 Particle Canvas** | Ambient interactive particle background on every page |
| **✍️ Role Rotator** | Animated text cycling through roles: Full Stack Dev, ML Enthusiast, Embedded Engineer |

| **🔮 Custom Cursor** | Glowing cursor effect that scales on interactive elements |
| **📜 Scroll Animations** | Reveal-on-scroll effects across all sections |
| **📬 Working Contact Form** | Integrated with [FormSubmit](https://formsubmit.co/) for real email delivery |
| **⚡ Zero Dependencies** | Pure HTML/CSS/JS — no frameworks, no build step, no npm |

## 🚀 Getting Started

### Run Locally

No build step required — just open in a browser:

```bash
# Clone the repo
git clone https://github.com/Kalyan-4406/kk-portfolio.git
cd kk-portfolio

# Option 1: Open directly
start index.html          # Windows
open index.html           # macOS

# Option 2: Local server (recommended for full functionality)
python -m http.server 3000
# Then visit http://localhost:3000
```

### Deploy to GitHub Pages

1. Go to your repo → **Settings** → **Pages**
2. Set Source: **Deploy from a branch** → `main` → `/ (root)`
3. Click **Save**
4. Your site will be live at `https://kalyan-4406.github.io/kk-portfolio/`

## 🎨 Design Highlights

- **Color Palette**: Deep dark (`#0B0B0F`) base with electric purple (`#A855F7`), pink (`#EC4899`), and orange (`#F97316`) accents
- **Glass Cards**: `backdrop-filter: blur(20px)` with subtle border glow on hover
- **Custom Scrollbar**: Gradient-colored scrollbar matching the theme
- **Noise Texture**: Subtle SVG grain overlay for depth
- **Micro-interactions**: Hover lifts, glow effects, staggered reveal delays
